# 📊 Employees Data Analysis Dashboard

This project presents an **interactive Employees Data Analysis Dashboard** designed to provide insights into workforce metrics such as employee count, salary distribution, performance scores, satisfaction levels, and departmental analysis.  
The dashboard helps management make **data-driven HR decisions** effectively.

## 📈 Visual Insights Explained

### 🔹 Salary Range Distribution
- Majority of employees fall under the **Mid salary bracket**
- Smaller proportion in **High** and **Low salary ranges**
- Helps assess salary structure balance

---

### 🔹 Employee Satisfaction Ratio
- Positive feedback dominates overall sentiment
- Identifies areas requiring employee engagement improvement

---

### 🔹 Employee Sentiment Analysis
- Categorized into:
  - Satisfied
  - Dissatisfied
  - Neutral
  - Unknown  
- Useful for understanding workplace morale

---

### 🔹 Employee Count Trend (Year-wise)
- Shows hiring trends over time
- Highlights growth and decline periods

---

### 🔹 Average Performance Score by Department
- IT and Sales show higher performance scores
- Marketing shows scope for performance improvement
- Supports department-wise training planning
